Privacy Policy

WHOOP Dashboard · last updated 9 September 2026

This is a personal, single-user project. It exists so one person can view their own WHOOP data. It has no accounts, no sign-up, and no users other than its owner.

What this application does

WHOOP Dashboard reads the owner's own health data from the official WHOOP API, using OAuth access that the owner granted to themselves, and renders it as charts on a static web page.

What data is accessed

Through the WHOOP API, using these scopes:

  • read:profile — basic profile information
  • read:recovery — recovery score, heart rate variability, resting heart rate, blood oxygen, skin temperature
  • read:cycles — daily strain, average and maximum heart rate, energy expenditure
  • read:sleep — sleep duration, stages, performance and efficiency
  • read:workout — logged activities with strain and heart rate
  • read:body_measurement — height, weight, maximum heart rate
  • offline — permission to refresh access without re-authorising each time

Access is read-only. Nothing is ever written back to WHOOP.

Where the data is stored

A scheduled GitHub Actions job fetches the data and commits it to this project's GitHub repository as data/whoop.json and data/whoop.csv. The web page reads those files directly in the browser. There is no database, no backend server, and no API of our own.

If the repository is public, these data files are public. Anyone can read them, and every past version remains in the public git history. This is a deliberate trade-off for free hosting on GitHub Pages, and it is the owner's own health data.

Credentials

WHOOP OAuth tokens are held as encrypted GitHub Actions secrets, available only to the workflow while it runs. They are never written into the repository, the data files, or the web page. WHOOP rotates the refresh token on each use; the workflow stores the replacement back into the same secret.

Who the data is shared with

No one. The data is not sold, transferred, or disclosed to any third party. There is no analytics, no tracking, no advertising, and no cookies.

Two service providers are unavoidably involved in serving the page:

  • GitHub hosts the repository and serves the site through GitHub Pages, and therefore receives visitors' IP addresses and request logs under GitHub's privacy statement.
  • Cloudflare (cdnjs) serves the Chart.js charting library to the visitor's browser, and therefore also receives the visitor's IP address and user agent. It receives no health data.

Retention

Data remains in the repository, including its git history, until the owner deletes it. Deleting the repository removes it. Because history is retained, removing a single past value requires rewriting git history rather than simply editing the current file.

Revoking access

The owner can revoke this application's access at any time from their WHOOP account settings, or by deleting the application at developer.whoop.com. Revoking stops all future data collection immediately. Data already committed to the repository is removed by deleting those files or the repository.

Children

This application is not directed at anyone under 16 and collects data from no one other than its owner.

Changes

Any change to this policy will be published on this page with a revised date above. The full revision history is visible in the repository.
